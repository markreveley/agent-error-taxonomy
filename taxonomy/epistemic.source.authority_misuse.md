# Source authority misuse

## Definition

A stale, historical, summarized, remembered, local, or secondary source is
treated as authoritative when a stronger or more current source exists.

## Inclusion criteria

- A meaningful source hierarchy exists for the claim.
- The agent selects or relies on a weaker source.
- A stronger source materially contradicts or supersedes the relied-on source.

## Exclusions and contrast cases

- Use `epistemic.evidence.scope_omission` when the relevant source surface was
  not searched at all.
- Use `epistemic.claim.synthesis_as_evidence` when agent-created inference is
  presented as source material.
- Mere disagreement between sources is insufficient unless the task establishes
  which source is authoritative for the claim.

## Examples

- `AET-EM-0006` — confirmed
- `AET-EM-0008` — confirmed
- `AET-EM-0031` — probable
- `AET-EM-0050` — confirmed
