# Incident records

Each Markdown file in this directory records one evidence-backed agent error.
Records use stable IDs and the template in [`_template.md`](_template.md).
The complete corpus record listing is in [`index.md`](index.md).

`primary_type` identifies the narrowest causal type supported by the evidence.
`secondary_types` are optional and must not be used as a catch-all list of
symptoms.
